🌿 Plant Guard – AI-Based Plant Disease Detection System
Plant Guard is an AI-powered web application designed to detect plant diseases from leaf images and provide basic information about symptoms, causes, treatments, and preventive measures. The project aims to help farmers, students, and gardeners identify plant diseases early and promote healthier plant growth.

🚀 Key Features
Disease Detection: Upload plant leaf images to identify potential diseases.
Multiple Plant Support: Supports crops such as Tomato, Potato, Corn, Apple, and Grape.
AI Integration: Supports custom machine learning models for disease prediction.
Treatment Suggestions: Provides disease information and preventive measures.
Scan History: Stores previous scans and supports CSV export.
User-Friendly Interface: Responsive design with English and Hindi language support.
Demo Mode: Simulated predictions when an AI model is unavailable.
🛠 Technology Stack
Frontend: React.js, Vite
Languages: JavaScript, HTML, CSS
Styling: Responsive CSS
AI/ML (Optional): TensorFlow or PyTorch
Backend (Optional): Python, Flask
Storage: Browser Local Storage
💻 Getting Started

npm install
npm run dev
npm run build
npm run lint
